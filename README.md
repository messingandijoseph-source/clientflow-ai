# ClientFlow AI

ClientFlow AI is an AI-powered mobile sales assistant built for African small businesses.

It helps entrepreneurs generate sales messages, follow-up content, promotional offers, and social media captions in seconds.

---

# Problem

Many African small businesses rely heavily on WhatsApp, Facebook, Instagram, and word-of-mouth marketing.

However, many business owners struggle with:
- attracting clients,
- following up with leads,
- writing persuasive messages,
- managing customer relationships.

---

# Solution

ClientFlow AI helps business owners:
- generate sales content using AI,
- manage leads,
- improve follow-ups,
- increase customer engagement,
- organize client interactions.
